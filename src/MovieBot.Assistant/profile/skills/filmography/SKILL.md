# Filmography

1. Settle which person. The famous one unless the question says otherwise; when person_credits lists other people with the name, say which one the list is of.
2. Turn "this year", "lately", "upcoming" and "early career" into from and to, from today's date in the reminder. One year is both set to that year.
3. person_credits with the right role: acting for an actor, directing or writing for a film-maker, any when it does not matter.
4. List oldest to newest with dates, one per line. Mark each as released, upcoming or announced as the tool says. A credit with no date is announced; say it has none.
5. For "worked with", discover with both names in with.
