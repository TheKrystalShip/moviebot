# Turning a remembered scene into a web search

web_search finds pages written by reviewers, news sites and fans. Write the query as they would write
the page, not as the person said the memory.

- **Name what happens and who it happens to.** "a woman wakes up and finds everyone in town has vanished", not "that movie with the empty town".
- **Add the kind of thing it is.** "film", "movie", "TV series", "horror film", "animated film".
- **Add the year or the decade when the person has it,** as a year range: "2003 film" or "1990s thriller". For anything recent, the year from today's date.
- **For news, use the news words:** "announced", "cast", "first look", "teaser", "trailer", "release date", "festival premiere".
- **Leave out names the person is unsure of.** A wrong name steers the search to the wrong film. Put a name in only when it is a firm clue.
- **Try one rephrasing before giving up:** the same scene with the setting instead of the plot, or the cast instead of the scene.
- **A search result is a lead, not a fact.** Take the title it suggests to title_details, and name the film only once the database agrees with the clues.
